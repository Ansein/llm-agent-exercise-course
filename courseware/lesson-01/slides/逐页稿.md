## 03｜客服效率与分类指标

- 意图正确：请求分到了正确类别
- 知识命中：返回了支持答案的证据
- 自动解决：无需人工且业务正确终结
- 本节测量第一项，不能代替后两项

讲师备注：解释自动解决率的分母是全部请求。分类调用耗时不等于客服处理时长。15—25分钟。

## 04｜业务标签与边界

- 取消订单 / 签收后退货 / 换货
- 退款进度 / 支付 / 发票
- 物流 / 修改收件信息 / 售前咨询
- 安装使用 / 保修维修 / 服务投诉

讲师备注：共12个已知类，unknown额外表示域外或需澄清。主诉求优先于被否定的背景。25—35分钟。

## 05｜合成数据的规模与局限

讲师备注：来源data/templates.json和unknown_templates.json。每类20核心表达；不可称为1200个独立语言样本。

- 测试：240条已知＋40条未知，最终评测

讲师备注：来源data/manifest.json。template_id包含标签，只用于审计。测试有效已知表达族48个。

## 07｜规则基线的执行逻辑

- 唯一意图命中：返回该标签
- 零命中或多意图命中：unknown，转人工
- 关键词透明、易检查，无需训练
- 局限：不理解否定范围和背景主次

讲师备注：打开src/baselines.py KeywordRules.explain；演示开具发票和不要取消只改地址。

## 08｜TF-IDF 的含义

- TF：片段在当前文本中出现的次数
- df：包含该片段的文档数
- 平滑 IDF = ln((1＋n)/(1＋df))＋1
- L2 归一化后输入分类器

讲师备注：35—48分钟。参考https://scikit-learn.org/1.7/modules/feature_extraction.html 。代码用字符2—4 gram，sublinear_tf=True。

## 09｜三个文档的手算例子

- D1：退款 到账；D2：退款 进度；D3：发票 开具
- IDF(退款)=1.287682；IDF(到账)=1.693147
- D1 归一化向量约为 [0.605349, 0.795961]
- 实际代码用字符片段；此例用词便于手算

讲师备注：先让学员算df，再算平方和开根号。完整过程见教师讲义。

## 10｜逻辑回归与训练边界

- 文本 → 字符2—4 gram → TF-IDF → 线性分类
- 每类分数：z = w·x＋b，再做 softmax
- 词表、IDF与分类参数只从训练集学习
- 最大类别分数不等于已校准的正确概率

讲师备注：48—60分钟。参考https://scikit-learn.org/1.7/modules/generated/sklearn.linear_model.LogisticRegression.html 。C=4，lbfgs，max_iter=1000。

## 11｜指标的分母

- F1 = 2TP / (2TP＋FP＋FN)
- macro-F1：12个已知类别的F1等权平均
- 已知被拒识仍计错，不能删掉后再算
- 未知误收：被路由到已知类的未知请求 / 40

讲师备注：课堂两类练习参考答案macro-F1约0.6751，准确率0.65。unknown不作为主已知macro-F1的第13类，但矩阵包含unknown。

## 12｜拒识阈值与错误成本

- 教学成本：已知错路由3、已知拒识1、未知误收5
- 只在验证集比较预设阈值
- 本次选定阈值：0.25；验证成本：0.7000
- 全部拒绝会失去覆盖率，不能叫自动解决

讲师备注：来源reference/baseline-v1/threshold-selection.csv。成本为教学相对单位，非企业核定金额。60—80分钟教师运行演示。

## 15｜更高 F1 不等于更低业务成本

- 规则：教学成本 0.8036 / 请求
- TF-IDF＋拒识：教学成本 0.8107 / 请求
- 强制分类F1为0.6100，但未知误收40/40
- 当前证据不支持直接自动办理业务

讲师备注：来源reference/baseline-v1/results.json。准确率与成本权重不同。不要根据测试为每个类别挑赢家再声称未见泛化。

## 16｜表达族重采样的不确定性

- 每个已知类4个测试表达族，族内5条一起采样
- 配对 bootstrap 1000次，比较F1差值
- 95%区间约为 [-0.1141, 0.1775]，跨0
- 范围只适用于此合成表达池

讲师备注：来源reference/baseline-v1/results.json bootstrap_95_percent。不是生产流量的置信保证，也不包括训练变异。
