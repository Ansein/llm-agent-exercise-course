## 新增内容与调整原因

第01—12课为用户明确提出、原图未逐课列出的基础和训练内容：传统NLP、张量、Transformer、BERT、GPT、提示、数据工程、从零训练、SFT/DPO、LoRA、QLoRA及推理服务。第22课增补Codex，第23课明确Harness定义。第43—44课增补企业综合集成与答辩。

授课顺序为基础→P07→P06→P08→P01→P02→P04→P03→P05→P09→P10→综合。先建立检索与工具调用，再讲运行时与数字员工，最后做跨领域交付。原项目编号保持不变，便于逐项追溯。

## 技术表述修订

- 原图的「最具影响力」「架构巅峰」「23阶段」「25+平台」等宣传或特定实现表述不作为技术事实和考核目标。课堂按锁定版本与实测能力授课。
- 「复刻Claude Code」收敛为分析公开能力、构建教学Harness，不宣称获得闭源内部实现。
- Git worktree提供独立工作副本；文件与网络安全必须由沙箱、权限和工具策略另行实施。
- 提示缓存、任务状态、长期记忆分别讲解。Skills组合不等于联邦学习；自动反馈不等于强化学习。
- Skills通用格式不保证通用`dependencies`自动安装；宿主扩展和兼容性单列核验。
- 不把某个模型的知识截止时间套用到所有LLM，也不声称RAG彻底消除幻觉。
- 提示教学侧重任务分解、工具轨迹、依据与结果校验，不要求输出模型隐藏思维链。
- 原图提及PyPDF2等库视为候选技术；实际实验库和版本由教师开课前选定并试跑，不将长图版本视为长期有效依赖清单。
