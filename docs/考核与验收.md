# 考核与验收

[返回课程总览](../README.md)

## 考核原则

课程指标是建议门槛，当前无任何已实测成绩。教师用实际批次环境预跑后，可在教学开始前校准并冻结；修改需记录理由。小测试集仅能支持教学范围结论，不能据此承诺生产SLA。所有安全目标中的「0次」只指指定测试集，不能表述为系统不存在漏洞。

每个结果附样本数、输入范围、版本、硬件、并发、配置与失败案例。正常、边界、越权、工具故障分层报告；只运行成功请求会产生幸存者偏差。

## 指标定义

| 指标 | 口径 | 注意事项 |
|---|---|---|
| macro-F1 | 各类别F1的等权平均 | 同时列各类样本量、召回与未知类误收 |
| Recall@K | 对每个问题计算Top-K覆盖的相关证据数/金标准相关证据数，再宏平均 | 无相关证据的问题单独评拒答，不能混入分母 |
| nDCG@K | 按人工相关性等级计算折损增益并归一化 | 明确相关性等级和K；使用同一标注 |
| 引用支持率 | 被对应引用证据直接支持的可核实陈述数/被评审可核实陈述总数 | 缺引用的陈述按未支持计；不只检查链接可打开 |
| 拒答召回 | 正确拒答的不可回答问题数/不可回答问题总数 | 另报可回答问题被误拒绝的比例 |
| 正确完成率 | 满足预定义业务终态与全部关键条件的任务数/所有发起任务数 | 超时、取消与异常不悄悄移除；正确转人工可另列，不默认为自动完成 |
| 自动解决率 | 无人工处理且业务正确完成的任务数/所有发起任务数 | 不能用单轮回复率替代；业务任务是否需人工由预先标签定义 |
| SQL执行结果准确率 | 与金标准结果在排序/数值规则下等价的问题数/所有测试问题数 | 可执行但结果错误算失败；语法通过率单列 |
| 公式结构正确率 | 结构与金标准一致或经指定规则确认数学等价的公式数/全部测试公式数 | OCR字符相似不等于结构或数学等价 |
| 数值正确率 | 在预设绝对/相对容差内的计算数/全部计算请求数 | 每题声明单位、定义域和多解规则 |
| P50/P95延迟 | 从接收请求到业务终态的端到端时长分位数 | 包含重试；记录超时比例与截止值，工具耗时可另拆 |
| 每成功任务成本 | 所有运行的可归属总成本/正确成功任务数 | 分子包含失败、重试；成功数0时记不可定义，不填0 |
| 越权泄漏/重复副作用 | 指定用例中发生的事件数与测试总数 | 任何一次均单独阻断本项目发布判定 |

API成本依据实际token/计费单位和测试时的单价快照计算；自托管成本列GPU时、存储和人工维护估算。不得把不含人工的调用费宣称为全部业务成本。处理时长节约若仅为离线代理，应写明尚无真实线上对照。

## 统一证据包

至少包含：任务和版本ID、数据manifest与切分、模型/框架/工具版本、配置与随机种子、基线与改进逐样本结果、测试日志、失败分类、资源费用、已知限制、README复现入口。生成结果有随机性时，关键Agent任务建议至少重复2次，报告运行间差异；基础训练如仅一次运行，明确不能声称统计显著。

## 项目评分（100分）

| 维度 | 分值 | 评审证据 |
|---|---:|---|
| 业务问题与基线 | 15 | 角色、业务流程、金标准、非大模型方案与比较理由 |
| 原理与选型 | 15 | 架构/损失/契约解释、参数或方案消融、复杂度取舍 |
| 任务正确性 | 25 | 冻结测试结果、分层错误、端到端而非只看中间指标 |
| 工程可靠性与权限 | 20 | 身份校验、失败恢复、幂等、资源隔离和审计 |
| 成本与性能 | 10 | 明确环境下的延迟、调用量、显存或费用及预算 |
| 复现与表达 | 15 | 可运行入口、版本数据记录、失败边界、答辩现场核验 |

建议70分通过、85分优秀；各项目硬门槛仍须满足。存在以下任一项不得判定交付通过：伪造测量或来源、测试答案污染训练且未修复、指定越权测试泄漏、真实越权副作用、隐藏关键事实/数值错误。修复后重测方可恢复评审，不以口头说明消除阻断项。

## 全课程成绩建议

基础课实验占30%，10项项目阶段交付合计40%（每项等权4%），综合项目与答辩占30%。仅完成选修方向时出具对应模块成绩，不颁称全课程完成。基础课无需生产部署，但须能解释张量、训练与微调实验；项目课必须有业务证据。

## 人工评审

对开放式答案事先制定正确、部分正确、错误和不可判定标准。至少20条关键样本由两人独立评审，分歧经证据复核。LLM-as-judge可辅助分类，但不能独立判定财务数值、SQL结果、越权、公式计算和关键事实。公开分歧与标注修订，不反向调整测试答案以迎合模型。
