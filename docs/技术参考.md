## 如何使用来源

- Transformer、BERT、GPT、LoRA、QLoRA与DPO采用论文机制进行教学，不把论文中的大规模成绩迁移成小型课堂实验的质量承诺。
- GPT类模型以自回归原理讲解，实际开放权重模型由教师选定；不使用未核验的“最新模型排名”作为主线。
- RAG和CLIP论文分别提供检索增强和图文表示的基础；权限、删除、故障、验收等属于本课程工程设计。
- Harness文章提供长任务运行设计参考，不是强制通用标准；课程仅概括其状态、工件和验证思路，再自行设计实验。
- Agent Skills规范用于区分入口描述、正文与资源；发现算法、依赖安装和允许工具均须核验具体宿主。
- Codex与Claude Code课程以公开文档和可见任务结果为依据，未声称了解闭源内部架构。
- OpenClaw资料用于核验Gateway与Skills概念，渠道、插件和元数据字段需依锁定版本逐项试跑。

每期开课前、产品发生重大接口变更时重新打开官方资料，记录核验日期、受影响课次、变更内容与回归结果。保留原有教学原理，更新环境和产品行为；任何“最新”“默认”“支持”等动态断言必须有明确范围。资料不可访问时标为待核验，不根据搜索摘要编造功能。
