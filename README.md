# 大模型与 Agent 企业实战课程大纲

从传统NLP与Transformer原理，到BERT/GPT、模型构建、LoRA/QLoRA，再到RAG、多模态、Agent、Codex及Harness工程。课程以可验证业务闭环为目标，既学习底层机制，也训练技术选型、失败诊断和企业交付能力。

## 课程依据与设计假设

本仓库原始资料为课程项目长图`微信图片_2026-09-14_152023_168.webp`（1143×10625）；该图仅在本机保留为来源证据，已按`.gitignore`排除，不随仓库公开发布，因此不在仓库内提供直达链接。长图题为「AI项目介绍」，包含10个项目方向，没有逐节课表、总课时或基础模型课程。因此这里保留原图P01—P10编号，按先修关系重新安排授课顺序，并根据用户要求补充模型基础、训练和Codex专题。拆课、课时、数据和验收门槛均为新增教学设计，详见[来源与课程映射](docs/长图来源与课程映射.md)。

- 建议对象：具备Python与基本软件开发经验的工程师、算法工程师、技术负责人；SQL、Git、线性代数不足者先完成课前补习。
- 总规模：44节，每节180分钟，共132小时课堂；课后每节2—3小时，共88—132小时（包含项目作业），总投入约220—264小时。
- 内容组成：12节模型基础与训练（36小时）＋10个项目各3节（90小时）＋2节综合交付（6小时）。
- 建议节奏：每周2节，共22周；或每周4节，共11周。训练预跑、共享GPU与课后项目时间另行安排。
- 当前状态：44节大纲及项目任务书已完成；已交付第01课与第02课完整教学包（讲义、数据、可运行实验、Notebook、实测报告与20页课件），其余课程仍以教学设计为主。第01课为规则与TF-IDF基线，第02课为字符编码与手写自动微分的均值池化分类器，两课共用同一冻结测试集与指标口径。设计门槛与实测结果分别标注。
- 初次技术参考核验：2026-09-14；每期开课前复核动态产品、协议与依赖，不承诺某一模型永久「最新」。

## 培养目标与业务主线

1. 能解释模型机制：从张量、注意力和训练目标推导BERT/GPT差异，完成小规模从零训练及参数高效微调实验。
2. 能选择合适方案：在统一任务上比较规则、传统机器学习、预训练编码器、LLM、RAG与Agent，允许简单方案胜出。
3. 能解决实际问题：围绕客服、知识检索、研究报告、多模态素材、数据分析和文档计算完成可审计闭环。
4. 能交付可维护系统：明确身份权限、状态恢复、幂等、评测、成本、监控、人工接管与灰度回滚。

贯穿案例采用虚构企业「星舟设备服务」：有客户咨询、设备手册、订单与退款、商品图片、培训视频和技术PDF。研究报告作为独立领域迁移项目。学员最终选择至少三类能力组成一条完整业务流程，不要求把十个项目硬拼成一个系统。
